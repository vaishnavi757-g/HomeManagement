# 🏠 Home Management System

A web-based Home Management System developed using Flask and SQLite.

## 🚀 Live Demo

https://home-management-system-ormb.onrender.com/

## 📌 Features

- 🔐 User Registration and Login
- 🚪 Secure Logout
- 📋 Task Management
  - Add tasks
  - Complete tasks
  - Delete tasks
- 💰 Expense Management
  - Add expenses
  - Delete expenses
  - Track total expenses
- 🛒 Shopping Management
  - Add shopping items
  - Mark items as completed
  - Delete items
- 📊 User-wise Dashboard
- 🔒 User-specific data isolation
- 📱 Responsive and clean UI

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- Git & GitHub
- Render
